**👥 Hospital Emergency Room Dashboard**

A comprehensive Hospital Emergency Dashboard built to uncover operational and patient care insights!

**📊 Dashboard Overview**
This dashboard consolidates data from April 2023 to October 2024, offering a deep dive into emergency room performance, patient demographics, and referral patterns.
This dashboard empowers hospital teams to optimize staffing, improve patient experience, and streamline referrals.

**🔍 Interactive Insights:**

**📊 Patient Volume:**
 → 9,216 patients visited between April 2023 and October 2024→ 50.04% were admitted, 49.96% not admitted—indicating balanced triage decisions

**⏱️ Wait Time & Efficiency:**
 → Avg wait time: 35.3 minutes
 → Only 40.68% were seen within 30 minutes—highlighting a need for faster response during peak hours

**😊 Satisfaction Score:**
 → 4.99/10—moderate satisfaction, with room to improve patient experience

**👥 Demographics:**
 → Age groups 20–39 made up the largest share
 → Gender split: 51% Female, 49% Male
 → Diverse racial representation, with White and African American patients forming the majority

**🩺 Referral Patterns:**
 → 5.4K patients required no departmental referral
 → General Practice and Orthopedics were the top referral destinations

**📅 Peak Load Hours:**
 → Busiest days: Monday, Tuesday, Saturday
 → Busiest hours: 07–10 AM & 5–8 PM—ideal windows for staffing optimization.

**🛠️ Tools Used**

Power BI Desktop (.pbix)
Power Query for data cleanup
DAX for KPIs and calculated columns

**🚀 Getting Started**
Download or clone this repository.
Open HRDashboard.pbix in Power BI Desktop.
Ensure dataset files are located in the dataset/ folder.
